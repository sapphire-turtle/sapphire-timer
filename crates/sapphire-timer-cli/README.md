# sapphire-timer-cli

The command line of [sapphire-timer](https://github.com/sapphire-turtle/sapphire-timer)'s
two editions: sapphire-framework's commands (`serve`, `status`, `service`, `workspace`,
`mcp`, …), the app server and the MCP server, as a library.

To install the command, see [`sapphire-timer-headless`](../../README.md#installation) (no GUI)
or the desktop app; both put `sapphire-timer` on PATH.
