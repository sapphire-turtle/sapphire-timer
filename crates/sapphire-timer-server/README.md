# sapphire-timer-server

The app server of [sapphire-timer](https://github.com/sapphire-turtle/sapphire-timer):
the one process that reads and writes the workspace's presets and logs, syncs it through
the host's `sapphire-bridge`, and answers the timer's methods and MCP tools.

It is a library, run as `sapphire-timer serve` by either edition
([`sapphire-timer-headless`](../../README.md#installation) or the desktop app).
